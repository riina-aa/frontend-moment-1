# frontend-moment-1

## Om 
I denna uppgift så ska vi skapa en webbplats med hjälp av NodeJs och Git/Github. Uppgiftens syfte är att lära oss hur verktyg kan effektivisera skapandet av webbplatser genom automatisering av vanliga arbetsmoment. Demowebbplatsen som vi ska skapa ska utvecklas med hjälp av HTML, CSS och JavaScript.
