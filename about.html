Min arbetsprocess

Jag började den här uppgiften med att följa Mattias video om hur man startar upp ett Vite-projekt som fanns i kursmaterialet. Jag följde stegen som Mattias tar för att konfiguera projektet med att lägga in några inställningar i vite.config.js-filen, skapade mina html-filer, gjorde undermappar för CSS och JS samt skapade filer för dessa. Jag laddade även ner ViteImageOptimizer för att kunna komprimera mina bildfiler i projektet. Därefter så började jag bygga webbplatsen som vanligt. Jag tycker om att göra klart sida för sida.
